Skrypt Lua — DaVinci Resolve API
Skrypt tworzy jeden timeline ze wszystkimi reelsami ułożonymi jeden po drugim, z przerwą (gap) ustawioną w kroku 1.

Jak uruchomić:
1. Otwórz DaVinci Resolve i projekt
2. Workspace → Console (lub Ctrl+F12)
3. Wklej skrypt → kliknij Run
4. Gotowe — timelines pojawią się w Media Pool 🎉
